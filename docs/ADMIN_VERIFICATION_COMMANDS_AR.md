# أوامر تشغيل لوحة الإدارة والتحقق منها

هذه الأوامر جاهزة لتشغّلها أنت في PowerShell. لم تُشغّل ضمن تجهيز هذه النسخة من الخطة. لا تنشئ بيئة اختبار ولا تنشر خدمات ولا تزرع بيانات. تحتاج الاعتماديات الموجودة في المشروع؛ إذا ظهر خطأ، أرسل اسم الأمر والنص الذي ظهر. تستخدم الأوامر Node مباشرة لتجاوز مشكلة مسار npm التي ظهرت في المراجعة السابقة، دون تغيير إعدادات جهازك.

نتيجة اختبار المنطق لا تغني عن تجربة المسار في التطبيقين وقواعد Firebase. لا يُسجل نجاح حالة قبول لمجرد أن أمرًا عامًا انتهى بنجاح.

## C01 تشغيل اللوحة لتجربتها بنفسك

```powershell
Set-Location -LiteralPath 'C:\Users\hp\OneDrive\Desktop\مشروع التخرج\Roshita_Admin_Panel'
node .\node_modules\vite\bin\vite.js --host 127.0.0.1 --port 5173
```

افتح العنوان الذي يظهر في الطرفية وسجل دخولك. يستخدم التطبيق إعداد Firebase الحالي. نفذ فقط السيناريوهات على السجلات والحسابات التي تختارها. ينتهي تشغيل الخادم عند ضغط `Ctrl+C`. لا يعني ظهور صفحة الدخول أن تسجيل الدخول أو بقية الوظائف قد اجتازت القبول.

## C02 بناء نسخة الإنتاج محليًا

```powershell
Set-Location -LiteralPath 'C:\Users\hp\OneDrive\Desktop\مشروع التخرج\Roshita_Admin_Panel'
node .\node_modules\vite\bin\vite.js build
```

النتيجة المتوقعة: انتهاء بناء Vite دون خطأ وتحديث مجلد `dist`. هذا بناء محلي وليس نشرًا. يمكن حفظ الخرج إذا رغبت:

```powershell
node .\node_modules\vite\bin\vite.js build 2>&1 | Tee-Object -FilePath .\admin-build-result.txt
```

## الأوامر التي تسلّم مع التعديلات اللاحقة

كل مهمة تعدّل الكود تسلّم معها أمر الفحص الخاص بها إذا أضيف ملف فحص فعلي، ومجلد تشغيله والنتيجة المنتظرة. تجهيز سكربت أداء أو فحص جديد لا يعني تشغيله؛ يظل التنفيذ بيدك. لا تشمل الحزمة الحالية أوامر `firebase deploy` أو تشغيل Emulator أو زرع بيانات أو اختبار حمل على خدماتك.

التسجيل والظهور والتنبيهات والخرائط والتقارير والإشعارات لها خطوات يدوية محددة داخل [بطاقات المهام](<C:/Users/hp/OneDrive/Desktop/مشروع التخرج/Roshita_Admin_Panel/docs/ADMIN_EXECUTION_TASKS_AR.md>). فتح DevTools وفحص استجابة الشبكة يدخل ضمن تحققك من الخصوصية؛ لا تكفي صورة تخفي الحقل في الجدول.

للأداء، جهّز لك T16 أمر القياس فقط بعد معرفة المسارات النهائية وإعدادات التشغيل التي تختارها. يبقى حد القبول 3 ثوانٍ للمعتاد و10 ثوانٍ للخريطة والتقرير، وP95 لا يتجاوز 3000ms في سيناريو الحمل المعتمد. لا توجد نتائج مقاسة جديدة في هذه الخطة.
