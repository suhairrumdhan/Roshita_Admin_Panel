# روشيتة — لوحة الإدارة، الحد الأدنى الوظيفي

التحديث مدمج داخل الواجهة الحالية والخلفية المشتركة الحالية. لم تُشغّل اختبارات أو بناء أو ترحيل أو نشر؛ ينفذ المستخدم أوامر النشر والقبول.

ابدأ من [أوامر النشر الانتقائي](docs/ADMIN_DEPLOY_COMMANDS_AR.md)، ثم استخدم [دليل قبول الحد الأدنى](docs/ADMIN_MINIMUM_HANDOFF_AR.md). [الحالة الحالية](docs/ADMIN_FIX_STATUS_AR.md) تفرق بين تنفيذ هذه النسخة وإغلاق الخطة الكاملة.

تتضمن الدخول، التسجيل، ظهور الصيدليات، المستخدمين، متابعة الطلبات والتأخر، التنبيهات، الخريطة، التقارير والرئيسية، الإشعارات وسجل التدقيق. لا إدارة حسابات أو أدوار للمشرفين، ولا حظر مستخدمين أو تغيير عمليات الصيدلية من اللوحة.

المشروع الحالي:

- الواجهة في هذا المجلد، React/Vite؛ Firebase Hosting ينشر `dist` بعد بناء ينفذه المستخدم.
- الخلفية وقواعد Firestore والفهارس في `user_app` GitHub repository. مجلد `functions` القديم داخل الواجهة ليس مصدر النشر.
- تعديلات الخلفية مدمجة في مشروع `user_application` نفسه؛ لا توجد نسخة خلفية منفصلة للتشغيل أو النشر.
- تفعيل وظائف الخلفية والفهارس وتهيئة القوائم الست ضروري قبل تجربة المسارات. يلزم حساب إداري فعال قائم.

تحسين أداء التقارير، حماية روابط المستندات القديمة، وبقية شروط الحماية والتوافق مؤجلة. لا تُعد النسخة مطابقة 100% قبل تحقق المستخدم وإغلاق البنود المتبقية.
